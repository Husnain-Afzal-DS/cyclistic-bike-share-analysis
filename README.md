# 🚴 Cyclistic Bike-Share Analysis

##  Project Overview

This project analyzes Cyclistic bike-share data to identify the differences between annual members and casual riders. The analysis was performed as part of the Google Data Analytics Capstone Project using Excel, MySQL, and Tableau.

---

##  Business Problem

Cyclistic wants to increase the number of annual members. The objective of this project is to understand how casual riders and annual members use bikes differently and provide data-driven recommendations to improve membership conversion.

---

## 🛠 Tools Used

- Microsoft Excel
- MySQL Workbench
- Tableau Public

---

## 📂 Dataset

- Dataset: Cyclistic Bike-Share Data (2023)
- Period: January – December 2023
- Final Cleaned Records: **5,714,805**

---

##  Data Cleaning

The dataset was cleaned and validated before analysis.

Cleaning steps included:

- Data validation
- Duplicate investigation
- Missing value analysis
- Date & time formatting
- Ride duration validation
- Outlier investigation

---

##  Analysis Performed

The project includes analysis of:

- Member vs Casual riders
- Average ride duration
- Bike type preference
- Monthly ride trends
- Weekly ride trends
- Hourly ride trends
- Top start stations
- Top end stations

---

##  Key Findings

- Members completed **3,655,725** rides.
- Casual riders completed **2,052,662** rides.
- Members averaged **12.07 minutes** per ride.
- Casual riders averaged **20.70 minutes** per ride.
- Electric bikes were the most frequently used bike type.
- Casual riders preferred weekends and tourist locations.
- Members primarily used bikes for weekday commuting.

---

##  Business Recommendations

- Promote memberships at tourist stations.
- Launch seasonal membership campaigns.
- Target frequent casual riders.
- Promote electric bike memberships.
- Offer personalized membership discounts.
